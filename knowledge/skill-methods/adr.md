# Metod för ADR

Använd när användaren vill dokumentera, granska eller ompröva ett arkitekturbeslut.

Beskriv titel och status, kontext, drivande krav, beslutsförslag eller fattat beslut, motivering, prövade alternativ och konsekvenser. Utvärdera särskilt säkerhet, driftsansvar, kostnader, datakonsistens och återställbarhet. Redovisa antaganden, risker samt kriterier för framtida omprövning. Om beslutet inte är fattat: märk det tydligt som utkast. Hitta inte på godkännande eller beslutsdatum.

Vid ADR-granskning: hitta saknade drivkrafter, felaktiga jämförelser och otestade antaganden. Föreslå konkreta förbättringar.
