# Runtimeparitetsrapport

## Bedömning

Chat ZIP och Custom GPT är båda funktionsdugliga och jämförs mot samma canonical capability-kontrakt.

| Capability | Kritikalitet | Chat ZIP | Custom GPT |
| --- | --- | --- | --- |
| Behovsanalys | critical | equivalent | equivalent |
| Arkitekturdrivande krav | critical | equivalent | equivalent |
| Mönsterrekommendation | critical | equivalent | equivalent |
| Avvägningar och alternativ | critical | equivalent | equivalent |
| Antaganden och osäkerhet | critical | equivalent | equivalent |
| Skydd mot överdesign | critical | equivalent | equivalent |
| Jämförelse och granskning | important | equivalent | equivalent |
| ADR-underlag | important | equivalent | equivalent |
| Strukturerad JSON | optional | equivalent | equivalent |
| Aktuell produktresearch | important | platform_dependent | platform_dependent |
| Hantering av uppladdade underlag | important | platform_dependent | platform_dependent |

## Slutsats

Ingen kritisk capability saknas eller är reducerad. Båda distributionerna innehåller samma canonical instruktion och samtliga sju Knowledge-filer. Skillnader gäller endast verktyg som måste aktiveras eller finnas i den omgivande plattformen.
